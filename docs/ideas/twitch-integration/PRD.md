# PRD: Twitch Integration (Idea)

## 1. 目的 (Objective)
ライブ配信プラットフォーム Twitch との連携を強化し、視聴者のチャットやアクションに対して AI アバターが直接反応するようにすることで、配信のインタラクティブ性を高める。

## 2. ユーザーストーリー (User Stories)
- 配信者として、チャットに書かれた質問に AI が自動で答えてほしい。
- 配信者として、レイドやサブスクライブなどのイベントに対して AI に独自のリアクションを取らせたい。
- 視聴者として、自分のコメントが AI に拾われて、キャラクターが自分の方を向いたり反応したりしてほしい。

## 3. 検討中の機能 (Proposed Features)
- **チャット・リスニング**: IRC または Twitch API を経由してチャットを取得し、LLM のコンテキストに送り込む。
- **特定タグの反応**: `!ask` などのコマンドや、AI の名前へのメンションに対する優先反応。
- **イベント・トリガー**:
    - フォロー・サブスク・レイド等のイベント検知。
    - イベントに対応した「特別な音声」と「特別な表情（Expression）」の再生。
- **チャンネルポイント連携**: ポイントを使用して「AI の性格を一時的に変える」「特定のアクションをさせる」などの機能。

## 4. 課題 (Challenges)
- **チャット過多への対応**: 勢いのある配信でのログ流速をどう制御（要約・間引き）するか。
- **認証**: OAuth 2.0 による安全な連携。
