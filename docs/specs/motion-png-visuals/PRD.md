# PRD: Motion PNG Visual System

## 1. 目的 (Objective)
デスクトップ上に立ち絵（Motion PNG形式を想定した静止画の組み合わせ）を表示し、音声に合わせた高精度なリップシンクと、生命感を与えるアニメーション（呼吸、まばたき）を提供することで、AIキャラクターとの「共存感」を視覚的に最大化する。

## 2. ユーザーストーリー (User Stories)
- 配信者として、背景が透過されたアバターをデスクトップの好きな場所に配置したい。
- AIの話し声に合わせて、アバターが「あ・い・う・え・お」の形で口を動かしてほしい（高い没入感）。
- 自分が喋っているときも、自分側のアバターが反応してほしい。
- 静止しているときも、呼吸やまばたきなどの微細な動きで「生きている感」を出してほしい。

## 3. 機能要件 (Requirements)
- **背景透過ウィンドウ**: キャラクターの周囲が完全に透過され、枠がない状態で表示されること。
- **高精度リップシンク**:
    - AI音声（WebSocket経由）およびローカルマイクの音声をリアルタイム解析。
    - 音圧（RMS）に基づく口の開閉。
    - 周波数解析（FFT）に基づく5母音（あ・い・う・え・お）の切り替え。
- **自然なアニメーション**:
    - JS駆動による「呼吸」の揺らぎ（1/fゆらぎ、黄金比を考慮した自然な周期）。
    - ランダムなタイミングでの「まばたき」。
- **柔軟なアセット管理**:
    - 目（開・閉）、口（あ・い・う・え・お・閉）、ベース立ち絵をディレクトリ分けして管理。
    - ユーザーが自由に画像を差し替えられること。

## 4. 非機能要件 (Non-Functional Requirements)
- **低レイテンシ**: 音声出力と口の動きのズレが認識できないレベルであること（Web Audio API / AudioWorklet の活用）。
- **低負荷**: 2つのアバターを常駐させても、CPU/GPUリソースを過度に消費しないこと。
- **マルチウィンドウ**: 自分とAIで別々のウィンドウと同期ロジックを持つこと。
