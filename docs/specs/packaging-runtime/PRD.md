# PRD: Packaging & Runtime System

## 1. 目的 (Objective)
ユーザーが Python のインストールやライブラリのセットアップを行うことなく、ダウンロードした一つのパッケージ（.app / .dmg）を実行するだけで Parcera を使用できるようにする「ポータブルな実行環境」を実現する。

## 2. ユーザーストーリー (User Stories)
- ユーザーとして、配布された DMG を開き、アプリケーションフォルダにコピーするだけで使い始めたい。
- ユーザーとして、バックエンドプロセスの起動や終了を意識せずに行いたい（アプリを閉じたら裏のPythonも消えてほしい）。
- ユーザーとして、モデルデータの肥大化を避け、必要なときにだけ必要なデータをダウンロードしたい。

## 3. 機能要件 (Requirements)
- **Portable Python 環境**:
    - アプリ内に独立した Python インタープリタとライブラリ（site-packages）を同梱すること。
- **Sidecar Guardian (監視)**:
    - Electron 起動時に Python エンジンを自動起動。
    - 予期せぬクラッシュ時の自動再起動（指数バックオフ）。
    - アプリ終了時の確実なプロセス・クリーンアップ（Zombies防止）。
- **Asset Management**:
    - モデルデータを App Bundle の外（User Data Directory）に保存し、再インストール時も維持されるようにすること。
- **マルチプラットフォーム基盤**:
    - Apple Silicon (arm64) へのネイティブ対応。

## 4. 非機能要件 (Non-Functional Requirements)
- **安定性**: 異なる macOS バージョン間でも、パス解決やライブラリの依存関係が崩れないこと。
- **サイズ最適化**: 不要な依存関係（PyTorch等）を削ぎ落とし、パッケージサイズを最小化すること。
