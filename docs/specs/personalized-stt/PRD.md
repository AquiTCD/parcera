# Personalized STT (MLX LoRA) PRD

## 1. 目的 (Objective)
パルセラ（Moonshine STT）が、ユーザー固有の滑舌、環境音、および特殊な語彙（格ゲー用語、ギャル語など）を完璧に理解し、
「世界で一番自分を理解してくれる相棒」としての体験を最大化すること。
MLXを用いたローカルでのLoRA追加学習により、高速性を維持したまま認識精度を劇的に向上させる。

## 2. ユーザー体験（Target Experience）
- ユーザーはアプリ内の「パルセラの特訓」セクションから、画面に表示される30〜50の特定のフレーズを読み上げる。
- 「特訓中...」の表示とともに、数分間のバックグラウンド処理で学習が完了する。
- 再起動不要、またはシームレスなモデル切り替えにより、すぐに「自分専用の耳」を手に入れたパルセラと会話できる。

## 3. 主要機能 (Main Features)

### 3.1 ガイダンス付き録音インターフェース
- 学習用フレーズを1つずつ提示。
- 音声入力をリアルタイムで波形表示。
- 録音と再生による確認機能。

### 3.2 自動データ・バリデーション
- 無音、極端なノイズ、想定時間を大幅に外れる録音を検知し、再録音を促す機能。

### 3.3 ローカル・トレーニング・エンジン
- Apple Silicon (GPU) を最大限に活用したMLX LoRA学習。
- 低VRAM消費での学習プロセス。

### 3.4 モジュール型アダプタ・プロファイル (Modular Profiles)
- 学習データ、メタデータ（作者、説明、バージョン）、および LoRA 重みを一つの「プロファイル」としてパッケージ化。
- プロファイルの保存、読込、削除、およびエクスポート/インポート機能。
- 追加学習（Retrain）による継続的なアップデート。

### 3.5 マルチ・アダプタ・スタッキング (Multi-Adapter Stacking)
- 複数のLoRAアダプタを同時に適用する機能。
- 例：「自分の声（Voice）」＋「格ゲー用語（Vocab）」の同時適用。
- 各アダプターの適用強度（Alpha）を個別調整可能なUI。

### 3.6 自律的学習サイクル (Self-Improving Cycle)
- 推論ログからの「口癖・固有名詞」自動抽出機能。
- ユーザーによる「誤認修正」履歴をベースにした特訓メニューの自動生成。
- ユーザーが最小限の手間で「自律走」できる学習エコシステムの構築。

## 4. 期待される効果
- **認識精度の極大化**: 「反確」「大パン」「シミー」などの特殊語彙の誤認識率を50%以上削減。
- **ユーザー体験の共有**: 「格ゲー特化」「VTuber用語特化」などのアダプタを友人やコミュニティで配布可能に。
- **メンテナンス性**: ベースモデルのアップデートに影響されず、必要なアダプタだけを使い続けられる。
- **ローカル完結型**: 全て手元のMacで完結し、プライバシーとコスト効率を両立。
