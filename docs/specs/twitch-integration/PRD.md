# PRD: Twitch Chat & Event Integration

## 1. 目的 (Objective)
ParceraをTwitch公式連携させ、視聴者とのリアルタイムな対話や配信イベント（Raid/Sub等）への自動反応を可能にすることで、配信のインタラクティブ性を最大化する。

## 2. ターゲット・ユーザー
- AIアバターを相棒として配信したいストリーマー
- 視聴者との距離を縮めたい配信者

## 3. 主要機能 (Core Features)

### 3.1 チャット・モニタリング & 応答
- **Wake Word 反応**: 「パルセラ」「Parcera」などのキーワードが含まれるチャットのみを拾う（トークン節約とスパム防止）。
- **メンション応答**: `@Parcera` へのリプライに対する優先的な返答。
- **パーソナライズされた応答**: 
    - チャットでの呼びかけに対し、必ず相手のユーザー名を添えて返答する（例：「〇〇さん、こんにちは！パルセラだよ！」）。
- **チャット読み上げツールとの共存**: 
    - 外部のチャット読み上げツール（棒読みちゃん等）と声が重ならないよう、**チャット의文字数に応じた動的な待機時間** を設けてから発話を開始する。
- **スマート・レートリミット**:
    - **Per-User Cooldown**: 同一ユーザーは60秒に1回まで反応。
    - **Global Cooldown**: 前回のチャット発話から10秒間は次のチャットを拾わない。
- **並列会話制御**: 配信者がパルセラと直接話している間（Voice Input優先）は、チャット応答をキューに入れるか、一時的に無視する。

### 3.2 配信イベント・リアクション (Event Interaction)
- **Raid 反応**: レイドを検知した際、LLMにコンテキストを渡し、特別な「歓迎」と「喜びモーション」を再生。
- **Subscription / Follow**: 新規のアクションに対し、お礼とキャラクター固有のリアクションを返す。
- **Cheer (Bits)**: 投げ銭の量に応じた「驚き」や「感謝」の強弱をつけたリアクション。

### 3.3 コンテキスト注入 (Streaming Context)
- LLMに対し、「今配信中であること」「現在の視聴者数」「最近のチャットの流れ」などのメタ情報を動的に注入し、配信者らしい振る舞いをさせる。

### 3.4 安全性とモデレーション (Safety & Moderation)
- **ユーザー・ブラックリスト**:
    - 指定したユーザーID（Bot、荒らしユーザー等）からの入力を完全に無視。
    - デフォルト除外対象: `Nightbot`, `StreamElements`, `Moobot`.
- **ワード・ブラックリスト (NGワード)**:
    - AIが読み上げるべきでない不適切な単語、差別用語、センシティブなキーワードを設定。
    - チャット受信時に正規表現でマッチングし、該当するのは処理を中断。

### 3.5 割り込み・優先度制御 (Interrupt Handling)
- **配信者優先原則**:
    - 配信者がパルセラと会話中（マイク入力がアクティブ、または返答生成中）にチャットで呼びかけられた場合。
    - **基本フロー (後回し)**: 配信者とのターンが終了してから、キューに溜まっていたチャットに返答。
    - **リアクション・フロー (視覚反応のみ)**: 音声では答えないが、アバターがチャット欄（カメラ外）を一瞬見る、または「👍」等の視覚的フィードバックのみを行う。
    - **緊急割り込み**: Raidや高額Cheerなど、特定の重要イベントのみ配信者との会話に割り込んで報告（設定でON/OFF）。

## 4. ユーザーエクスペリエンス (UX)
- 視聴者がチャットで話しかけると、パルセラが声（TTS）とテキストで反応する。
- 配信者が忙しい時も、パルセラがリスナーと遊んでくれる「共同配信者」としての体験。

### 4.1 認証・連携エクスペリエンス (Authentication Experience)
- **ワンクリック・ログイン**:
    - 設定画面の「Twitchと連携」ボタンを押すと、OAuth 2.0 認可フローが開始され、Twitch 公式の認可ページが開く。
    - ユーザーが承認するだけで連携完了。複雑な API キーの取得・コピペは一切不要。
- **安心・安全な権限管理**:
    - 必要最小限の権限（チャット読み取り、イベント取得等）のみを要求。
    - トークンはデバイス内に安全に保存され、いつでも連携を解除可能。

## 5. 追加アイデア (Brainstorming)
- **エモート連動リアクション**:
    - チャットが特定のスタンプ（草、w、8888等）で溢れた際、アバターが笑ったり拍手したりするモーションを自動再生。
- **配信テンション同期**:
    - チャットの流速（VPM: Votes Per Minute）を計測し、速いときはアバターの瞬きや動きを活発にする。
- **Twitch Points 連携**:
    - チャンネルポイント消費で「パルセラの性格が1分間変わる」「特定のポーズをとらせる」等の遊びを提供。
- **カメラ目線制御**:
    - チャット応答時は「視聴者（カメラ）」を向き、配信者との会話時は「配信者（横）」を向くように視線を切り替える。

## 6. 制約事項 & 非機能要件
- **安全性**: Twitch AutoModやLLMのフィルタリングを介した不適切発言の防止。
- **リアルタイム性**: チャット受信から発話開始まで3〜5秒以内を目標とする。
