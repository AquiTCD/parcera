# PRD: GUI Settings System

## 1. 目的 (Objective)
ユーザーが YAML ファイルを直接編集することなく、直感的な UI を通じてアバターの性格、音声エンジン、システム動作をカスタマイズできるようにする。

## 2. ユーザーストーリー (User Stories)
- ユーザーとして、複雑な設定ファイルを触らずにマイク感度やAIの名前を変更したい。
- ユーザーとして、変更した設定が即座に（あるいは保存ボタン一つで）反映されるのを確認したい。
- ユーザーとして、モデルのダウンロード進捗を視覚的に把握したい。
- ユーザーとして、何かトラブルがあったときにログを画面上で確認したい。

## 3. 機能要件 (Requirements)
- **タブ形式のカテゴリ分け**:
    - AIプロファイル、音声認識(耳)、思考(頭脳)、音声合成(口)、アバター視覚設定、システム設定、ログ。
- **動的フォーム**:
    - 文字列、数値、チェックボックス、ドロップダウンによる各設定項目の入力。
    - APIキーなどの秘匿情報の入力。
- **ディレクトリ選択**:
    - OS標準のダイアログを用いたアセットパスの指定（`selectDirectory`）。
- **エンジンの初期化・リセット**:
    - 設定をデフォルトに戻す機能。
    - モデルのキャッシュ確認とダウンロードトリガー。
- **リアルタイム・モニタリング**:
    - マイクの入力レベルメーター。
    - Pythonエンジン（Sidecar）からのリアルタイムログ表示。

## 4. 非機能要件 (Non-Functional Requirements)
- **永続性**: 設定変更が `settings.json` (または `.yaml`) に正確に保存され、次回の起動時にも維持されること。
- **同期**: Electronのメインプロセスとレンダラープロセス間で、IPC (Inter-Process Communication) を通じて設定データが矛盾なく同期されること。
- **使いやすさ**: モダンで清潔感のあるダークモード UI。
