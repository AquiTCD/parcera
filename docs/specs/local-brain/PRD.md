# Local Brain (Gemma 2 MLX) PRD

## 1. 目的 (Objective)
外部APIへの依存を完全に排除し、Apple Siliconのパワーを最大限に活用することで、爆速かつプライベートな「パルセラの脳」をローカルに構築すること。
LoRA学習によるパーソナライズを組み合わせることで、ユーザー（アキさん）特有の文脈や語彙を完璧に理解する、阿吽の呼吸の会話体験を実現する。

## 2. ユーザー体験 (Target Experience)
- **究極のレスポンス**: ネットワーク遅延ゼロで、話しかけた瞬間に思考が開始され、ストリーミングで回答が返ってくる。
- **安心のプライバシー**: 会話内容は一切外部に送信されず、完全にMac内で完結する。
- **育てていくAI**: 過去の会話や特定の知識を「特訓」として学習させることで、パルセラが自分だけの相棒として進化していく。

## 3. 主要機能 (Main Features)

### 3.1 Gemma 2 9B ローカル推論統合
- `mlx-lm` を使用したApple Silicon最適化推論。
- 4-bit 量子化モデルによる VRAM 節約と高速化。
- 回答のストリーミング表示/読み上げ。

### 3.2 2フェーズ実装アプローチ
- **Phase 1: ローカル推論エンジン**: 学習なしの状態で Gemma 2 を動かし、既存のLLM（Google AI 等）と切り替え可能にする。
- **Phase 2: LoRA学習・パーソナライズ機能**: アプリ内でのデータセット構築およびLoRA学習の実行・アダプタ適用。

### 3.3 学習データの自動・手動収集
- 良い反応だったログを学習用データセット（JSONL）へエクスポートする機能。
- 特定の用語や性格付けを焼き込むためのプロンプト/データ管理。

### 3.4 リソース最適化
- システムメモリ残量に応じたモデル・ローディング管理。
- 学習時のGPU負荷制御。

## 4. 期待される効果
- 月額APIコストの削減。
- オフライン環境での完全動作。
- 汎用LLMでは不可能な、狭く深い「身内ノリ」や「格ゲー専門知識」への完全対応。
